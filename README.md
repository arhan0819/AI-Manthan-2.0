# AI-Manthan 2.0 - Smart Visual Defect Inspection

Automated bottle inspection system using computer vision and YOLOv8.

## Project Overview
This project performs real-time defect classification and visual inspection (checking fill levels, cap fit, and label alignment) and interfaces with a web dashboard.

## File Overview
- `ai_model.py`: Core AI inspection logic and YOLO inference pipeline.
- `main.py`: Backend server and detection orchestration.
- `train.py`: Model training script.
- `Neuro.Detect.html`: Web dashboard and visual monitoring UI.
